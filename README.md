# Cliniqo

**Book Your Doctor Appointment Instantly**

A modern, user-friendly doctor appointment booking platform built with **Next.js** and **TypeScript**. Connect patients with top-rated specialists, book appointments in seconds, and manage your healthcare journey seamlessly.

**Live Site:** [https://doc-appoint-client-pi.vercel.app/](https://doc-appoint-client-pi.vercel.app/)

## ✨ Features

- **Instant Appointment Booking** — Search and book doctors by specialty, availability, or symptoms in just a few clicks.
- **Top-Rated Specialists Directory** — Browse verified doctors with detailed profiles, ratings, and next available slots.
- **Smart Search & Filters** — Find the right doctor based on specialty, location, experience, or patient reviews.
- **Seamless User Experience** — Clean, responsive interface optimized for both desktop and mobile devices.
- **Real-Time Availability** — View live slots and receive instant confirmation with reminders.
- **Patient-First Design** — Built with a focus on ease of use, accessibility, and trust (verified doctors, high satisfaction rate).

## Tech Stack

- **Frontend:** Next.js 14+, TypeScript, Tailwind CSS
- **Deployment:** Vercel
